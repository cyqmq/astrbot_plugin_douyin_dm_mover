三、组装方式（CardsTestTab 如何拼）

父层用 CSS Grid 固定四区位置（列 minmax(96px,1fr) / minmax(0,3.5fr) / minmax(88px,1.3fr)，行 minmax(0,3fr) / minmax(96px,1fr)）：

  • TestRegionA → grid-column:1; grid-row:1/3（左全高长条）
  • TestRegionB → grid-column:2; grid-row:1（中上最大）
  • TestRegionD → grid-column:3; grid-row:1（右上长条）
  • TestRegionC → grid-column:2/4; grid-row:2（下排横跨 B+D 宽）

数据流

CardsTestTab（父层持有状态） │ ├─> A: 模板列表（:templates / :selectedId） │ <-- select(t) → selectedId=t.id │ <-- create() → 新建空白模板 + persist() │ ├─> B: 画布（:cards=selectedTemplate.blocks || null，:template-id / :add-request / :export-signal） │ <-- change(list) → t.blocks=list + persist() │ <-- export(p) → 组装完整 JSON 并触发下载 │ <-- preview(cards)→ 预览回调 │ ├─> C: 积木库（@add=addBlock） │ <-- add({type,kind,label}) → 确保有选中模板 → addRequest={seq,type,kind,label} → B 插入 │ └─> D: 属性面板（:selected=selectedTemplate，:form-error） <-- save({name,msg_type}) → 更新模板 + persist() <-- delete() → 移除模板 + persist() <-- export() → exportSignal++ → B 导出

四、关键实现要点

  • kind 细类型：type 是粗分类（约束/配色），kind 是细类型（内容语义）。B 区 KIND_INFO 定义每种 kind 的属性字段；KIND_FAMILIES 定义可互切家族（按钮/链接按钮、转发/自定义图片、转发/自定义视频）。
  • 行约束：B 区 rowViolation 按吸附行强制排版——①按钮固定底部 ②独占规则 ③同类型上限 ④整页按钮行 ≤5。
  • 边缘滚动：仅拖动卡片时触发（mode==='card'）、仅实际移动 >3px 后生效、以画布真实窗口边缘为界（getBoundingClientRect()）、向拖动方向滚。
  • 右键菜单：画布级 @contextmenu.prevent 拦截 + Teleport 到 body + fixed 视口坐标；项 = 类型（家族子菜单）/属性（按 kind 动态字段）/复制/删除。
  • 导出：按住 D 区保存按钮 ≥600ms → exportSignal → B 区按行分组输出 {rows:[{row_index,text,cards:[{type,kind,label,url,value,x_cell,width_cells}]}]}。
